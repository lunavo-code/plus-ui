# 用户管理页组件试点

## 组件接口

| 组件 | 页面传入的内容 | 组件负责 |
| --- | --- | --- |
| `CrudSearch.vue` | 标题、查询模型、搜索和重置回调、默认插槽中的筛选字段 | 折叠、表单提交和字段重置 |
| `CrudTable.vue` | 行数据、分页、列配置、`permission` 和行操作显示规则。默认插槽定义表格列，`toolbar-actions`、`more-actions` 和 `row-actions` 提供扩展操作。 | 卡片、工具栏、标准新增修改删除入口、行操作列、多选和分页 |
| `CrudFormDialog.vue` | `open(title, load)` 的标题和表单加载回调、校验规则、提交回调、默认插槽中的表单字段 | 弹窗生命周期、表单校验、防止重复打开或提交、成功后发出 `saved` |

## 用户管理页接入

- `composables/useUserForm.ts` 集中维护表单默认值、校验、详情加载、部门岗位联动和保存。
- `composables/useUserImport.ts` 集中维护上传、响应转换和模板下载。页面负责打开弹窗以及完成后的列表刷新。

- 页面传入用户权限、列显隐存储键和内置账号判断。解锁、导入导出、下载模板、重置密码和角色分配通过表格插槽接入。
- `permission` 接收完整权限码。传入字符串时，新增、修改和删除共用该权限码。用户管理后端按操作授权，因此试点通过同一属性传入三个完整权限码。
- 页面维护用户表单默认值、校验规则、部门岗位联动、角色选项以及新增和修改接口。弹窗通过默认插槽提供当前表单模型。
- `CrudImportDialog.vue` 负责 Excel 文件选择、可选的覆盖选项、上传状态和结果展示。页面传入 `upload(file, { overwrite })` 和可选的 `downloadTemplate`，并在收到 `completed` 后刷新列表，覆盖部分记录已经写入的情况。组件试点范围为 `src/views/system/user`。

## 后续模板落点

单表和树表入口可按字段元数据生成筛选项、列表列、表单项和校验规则，并把业务权限、列显隐存储键及接口回调传给三个组件。先在用户管理页验证筛选重置、权限组合、多选与分页、列显隐持久化、新增编辑和保存失败场景。
